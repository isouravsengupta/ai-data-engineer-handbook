# Docs Overview

Execution and quality-control documents for publishing and learner navigation.

## Files

- `ZERO_TO_HERO_BLUEPRINT.md` - beginner path and weekly/daily execution model
- `PUBLISH_EXECUTION_PLAN.md` - publishing definition of done and operating model
- `TOPIC_REVISION_BACKLOG.md` - tracked queue of chapter revisions
- `CHAPTER_EXERCISE_MAPPING.md` - chapter-to-practice connection map
- `PHASE_PUBLISH_READINESS_CHECKLIST.md` - objective per-phase readiness checklist

## How to Use

1. Start with `ZERO_TO_HERO_BLUEPRINT.md`
2. Execute using `PUBLISH_EXECUTION_PLAN.md`
3. Track and close revision items in `TOPIC_REVISION_BACKLOG.md`
