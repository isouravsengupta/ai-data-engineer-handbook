# Notebooks

This folder is for hands-on experiments, explorations, and reproducible demos.

## Notebook Types

- concept walkthrough notebooks (e.g., SQL windows, embeddings)
- experiment notebooks (benchmarking model/vector settings)
- pipeline debug notebooks (data quality checks, profiling)
- interview prep notebooks (quick proofs and visual explanations)

## Notebook Quality Checklist

- clear objective at the top
- deterministic setup cells
- small sample data or documented source
- final section: key takeaways
- optional: next-step productionization notes
