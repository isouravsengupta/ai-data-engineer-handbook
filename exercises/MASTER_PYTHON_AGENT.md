# Master Python Agent Plan (Now -> 23 Aug 2026)

This is your execution system for becoming interview-ready for top companies in Senior Data/AI Engineering roles with a strict `2.5 hours/day`.

## Mission

- Master Python deeply for coding interviews and production-grade data/AI engineering.
- Solve enough DSA medium/hard questions to perform under pressure in any interview round.
- Build system design and data engineering depth in parallel so coding + architecture rounds are both strong.

## Time Budget (Non-Negotiable)

- Daily: `2h 30m` (150 minutes)
- Weekly: `6 days execution + 1 day light review/mock`
- Minimum consistency target: `90%+` completion of planned sessions

## Daily Session Structure (150 min)

- `10 min` Warm-up: previous mistakes + one quick syntax/logic recap
- `60 min` DSA coding (timed): 2 problems (or 1 hard), write clean Python
- `40 min` Core DE/SQL/System Design concept from roadmap
- `30 min` Implementation drill (script, mini exercise, or optimization)
- `10 min` Review log: note errors, patterns, and tomorrow's focus

## Performance Targets

- Easy: <= 12 minutes, clean first pass
- Medium: <= 25 minutes
- Hard: <= 45 minutes with correct approach discussion
- By Aug 2026 target mix: ~`220-280` solved problems with strong pattern coverage
  - Easy: 40-60
  - Medium: 130-170
  - Hard: 50-70

## Interview-Level Rules

- Always state:
  - brute-force approach
  - optimal approach
  - complexity (`time` and `space`)
  - edge cases
- Code must include:
  - clear naming
  - typed signatures where useful
  - no hidden global state
  - tests/examples for key cases

## Weekly Cadence

- Day 1-4: intense build (new concepts + new problems)
- Day 5: mixed timed set (2 medium + 1 hard)
- Day 6: mock interview day (coding + architecture answer out loud)
- Day 7: active recovery (review mistakes, no burnout)

## Confidence and Offer-Level Standard

Goal is not just "solving questions", but "communicating like a senior engineer":

- crisp thought process
- trade-off reasoning
- production-grade coding habits
- calm under time pressure
