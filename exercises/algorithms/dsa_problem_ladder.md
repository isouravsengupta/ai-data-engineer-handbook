# DSA Problem Ladder (Python-First)

Use this list as your default queue after finishing the roadmap item of the day.

## Stage 1 - Core Patterns (Foundation)

- Arrays/Hashing: Two Sum, Product of Array Except Self, Group Anagrams
- Two Pointers: Valid Palindrome, Container With Most Water, 3Sum
- Sliding Window: Longest Substring Without Repeating, Permutation in String
- Stack: Valid Parentheses, Min Stack, Daily Temperatures
- Binary Search: Search Rotated Sorted Array, Koko Eating Bananas
- Linked List: Reverse Linked List, Merge Two Sorted Lists, LRU Cache

## Stage 2 - Interview Core (Medium Heavy)

- Trees: Level Order Traversal, Validate BST, Lowest Common Ancestor
- Tries: Implement Trie, Word Search II
- Backtracking: Subsets, Combination Sum, N-Queens
- Heap/Priority Queue: Top K Frequent, Find Median from Data Stream
- Intervals: Merge Intervals, Meeting Rooms II
- Graphs: Number of Islands, Clone Graph, Course Schedule

## Stage 3 - Senior-Level Pressure Set (Hard Focus)

- Hard DP: Edit Distance, Distinct Subsequences, Burst Balloons
- Hard Graph: Word Ladder, Reconstruct Itinerary
- Hard Sliding Window/Deque: Sliding Window Maximum
- Hard Heap/Merge: Merge K Sorted Lists
- Hard Arrays: Trapping Rain Water, Median of Two Sorted Arrays
- Hard Design: LFU Cache, Design Search Autocomplete System

## Solve Protocol (Every Problem)

- 1) State naive approach
- 2) Derive optimal approach
- 3) Write clean Python
- 4) Dry run with edge case
- 5) State complexity clearly
- 6) Log mistake category in tracker

## Mistake Categories

- Pattern recognition
- Off-by-one / index bug
- Complexity misjudgment
- Forgot edge case
- Data structure mismatch
- Incomplete communication
