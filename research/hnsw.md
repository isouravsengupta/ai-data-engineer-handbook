# HNSW

## Why It Matters

HNSW is one of the most effective ANN graph methods for high-recall vector search with low latency.

## Core Ideas

- layered graph navigation
- greedy search on proximity graph
- tunable construction and query parameters

## Engineering Takeaways

- excellent latency/recall balance for many workloads
- index build time and memory usage can be high
- tune parameters for data size and SLA targets
