# GitHub Strategy

Building a strong GitHub profile for AI Data Engineering.

## Profile Checklist

- clear headline and bio
- pinned repositories aligned to target role
- consistent commit history
- project READMEs with architecture and results

## What Recruiters Should See in 30 Seconds

- one flagship AI project
- one strong data engineering project
- one systems/inference project
- clean docs and practical benchmarks

## Weekly GitHub Actions

- push meaningful updates 4-5 days/week
- improve one README each week
- add one architecture diagram every 2 weeks
- track open issues and close stale TODOs
