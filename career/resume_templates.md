# Resume Templates

Templates and tips for AI Data Engineer resumes.

## Resume Structure (1-2 pages)

- Header: name, location, email, GitHub, LinkedIn
- Summary: 3-5 lines with years, stack, impact
- Skills: languages, data tools, cloud, AI stack
- Experience: impact bullets with metrics
- Projects: 2-4 relevant portfolio projects
- Education/Certifications

## Bullet Formula

`Action verb + what you built + scale/context + measurable result`

Example:

- Built a streaming ingestion pipeline on Kafka and Spark processing 40M events/day, reducing end-to-end latency from 18 min to 4 min.

## Priority Keywords (ATS + recruiter scan)

- Python, SQL, Spark, Airflow, Kafka
- lakehouse (Delta/Iceberg), dbt
- vector databases, RAG, LLM inference
- observability, reliability, cost optimization

## Common Mistakes

- listing tools without outcomes
- no metrics in bullets
- vague project descriptions
- too many low-signal skills
