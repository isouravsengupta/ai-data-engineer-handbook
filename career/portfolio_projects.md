# Portfolio Projects

Project ideas and how to showcase them for top-tier data/AI roles.

## Portfolio Rule

You do not need many projects. You need 3-5 strong ones with clear business value, architecture, and measurable outcomes.

## Recommended Portfolio Set

1. Vector search engine
2. End-to-end RAG pipeline
3. Distributed data pipeline (batch + streaming)
4. Spark/lakehouse optimization case study
5. LLM inference service with observability

## What Each Project README Must Include

- problem statement
- architecture diagram
- stack used and why
- local run steps
- benchmark/metrics section
- scaling and failure mode notes
- future improvements

## Evaluation Rubric (Self-Check)

- clarity: can a stranger run it quickly?
- depth: does it show trade-off thinking?
- reliability: retries, validation, observability considered?
- impact: any measurable improvement shown?

## Interview Conversion

Prepare a 2-minute and 10-minute explanation for each project:

- 2 min: what it is, why it matters, key result
- 10 min: architecture, decisions, trade-offs, bottlenecks
