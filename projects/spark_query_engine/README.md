# Spark Query Engine

End-to-end project: build or optimize a Spark SQL query engine over lakehouse storage.

## Learning Outcome

- optimize distributed SQL execution patterns
- reason about partitioning, caching, and shuffle behavior
- profile query plans and performance bottlenecks

## Milestones

1. load sample lakehouse datasets
2. implement baseline queries
3. inspect query plans and bottlenecks
4. optimize joins, partitioning, and caching
5. benchmark before vs after

See `book/03_sql_query_engines/`, `book/04_data_engineering_systems/`, `book/05_data_storage_lakehouse/` for theory.
