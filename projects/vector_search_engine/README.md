# Vector Search Engine

End-to-end project: build a vector search engine using embeddings and ANN (e.g. FAISS, HNSW).

## Learning Outcome

- understand embedding pipelines
- implement ANN search
- evaluate recall/latency trade-offs

## Milestones

1. ingest small text corpus
2. generate embeddings
3. index with FAISS/HNSW
4. run top-k search API
5. evaluate relevance and latency

## Deliverables

- runnable script or service
- benchmark table (latency + recall)
- architecture diagram in `diagrams/`

See `book/10_embeddings_vector_databases/` for theory.
