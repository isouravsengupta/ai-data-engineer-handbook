# LLM Inference Server

End-to-end project: serve an LLM with batching, streaming, and observability (e.g. vLLM, Ray Serve).

## Learning Outcome

- design an inference service with production behavior
- handle latency, throughput, and cost trade-offs
- instrument traces, metrics, and logs

## Milestones

1. model serving baseline API
2. request batching and streaming
3. observability instrumentation
4. concurrency/load testing
5. scaling and failure scenario notes

See `book/12_ai_infrastructure_inference/` for theory.
