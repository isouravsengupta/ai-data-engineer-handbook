# Distributed Data Pipeline

End-to-end project: design and implement a distributed data pipeline (e.g. Spark, Kafka, or Flink).

## Learning Outcome

- design resilient data movement at scale
- reason about throughput, retries, and idempotency
- monitor pipeline health and lag

## Milestones

1. source connector and ingestion layer
2. transformation layer (batch or streaming)
3. sink + storage strategy
4. retry and dead-letter handling
5. monitoring and SLO metrics

See `book/04_data_engineering_systems/` and `book/06_distributed_systems/` for theory.
